# Ecommerce-Sales-Dashboard
Ecommerce Sales Dashboard built in Power BI to analyze sales, profit, quantity, customer behavior, and payment trends. Features interactive filters, state-wise performance, monthly profit analysis, category insights, and KPI tracking, helping businesses make data-driven decisions through clear and dynamic visualizations. 🚀
Project Description for GitHub
Ecommerce Sales Dashboard | Power BI

An interactive Ecommerce Sales Dashboard built using Power BI to analyze sales performance, profitability, customer behavior, product categories, and payment trends. The dashboard provides valuable business insights through dynamic visualizations and filters, enabling data-driven decision-making.

Key Features
📊 Sales, Profit, Quantity, and Average Order Value (AOV) tracking
📅 Quarterly data analysis with interactive filters
🗺️ State-wise sales performance comparison
🛍️ Category and sub-category sales insights
💳 Payment mode distribution analysis
👥 Top customer contribution analysis
📈 Monthly profit trend visualization

Dashboard Insights
Total Sales: 438K
Total Profit: 37K
Total Quantity Sold: 6K
Average Order Value: 121K
Clothing category contributes the highest quantity sold (63%)
Cash on Delivery (COD) is the most preferred payment method (44%)
Maharashtra records the highest sales among all states
Printers generate the highest profit among sub-categories
Technologies Used
Power BI
DAX (Data Analysis Expressions)
Power Query
Microsoft Excel/CSV Dataset
Business Value

This dashboard helps businesses monitor key performance indicators (KPIs), identify profitable product categories, understand customer purchasing behavior, and optimize sales strategies through data visualization.
